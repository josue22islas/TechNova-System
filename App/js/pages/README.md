# JavaScript exclusivo de cada vista

Aquí irá la coordinación de cada página.

Ejemplos previstos:

- `dashboard.js`: solicita el resumen y actualiza la vista dashboard.
- `projects.js`: carga, filtra y actualiza la vista de proyectos.
- `tasks.js`: coordina la vista de tareas.

Estos módulos pueden utilizar funciones de `js/api/` y `js/components/`.
